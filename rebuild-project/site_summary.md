# MMWAFRIKA PRIDE COUTURE Website - Site Summary

## Project Overview
The MMWAFRIKA PRIDE COUTURE website is an e-commerce platform focused on selling handcrafted crochet items. The platform showcases a beautiful, modern design with a focus on artisanal products, featuring traditional crochet craftsmanship and artistic expression.

## Technology Stack
- **Framework**: Next.js 16.1.6 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS with custom CSS variables
- **Icons**: Heroicons and Lucide React
- **Fonts**: Manrope (primary), Playfair Display (serif)
- **Deployment**: Built for production deployment

## Design System & Styling
- **Color Palette**: 
  - Primary: Gold (#f2b90d) - represents luxury and warmth
  - Backgrounds: Light (cream/beige tones) and Dark (deep browns/charcoals)
  - Text: Black and white with varying opacities
- **Typography**: 
  - Primary: Manrope font for body text
  - Serif: Playfair Display for headings
- **Theme**: Supports both light and dark modes with smooth transitions

## Core Components
- **Header**: Responsive navigation with mobile menu, search, cart, wishlist, and theme toggle
- **ProductCard**: Displays product information with hover effects and quick view functionality
- **Footer**: Comprehensive footer with multiple sections
- **Cart**: Full-featured shopping cart with quantity adjustment and pricing
- **QuickView**: Modal for viewing product details without leaving the page

## Page Structure
- **Homepage**: Hero section, featured products, brand ethos, new arrivals
- **Shop**: Product listings with advanced filtering and sorting
- **Product Detail**: Individual product pages with full specifications
- **Cart**: Shopping cart functionality
- **Checkout**: Order processing flow
- **Admin Dashboard**: Extensive backend functionality (see below)
